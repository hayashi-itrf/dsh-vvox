# dsh-vvox — DSH VOICEVOX読み上げ

DSHが文章を書いている途中から、Mac上のVOICEVOXで読み上げるプラグインです。**読み上げは日本語のみ対応です。** 返答は翻訳せず読み上げます。日本語以外の部分が混ざると、省略されたり、日本語の読み方になったりすることがあります。
**音声はWeb Audio APIでDSH内から再生します。** VOICEVOXの対応状況に応じて、ストリーミング合成と通常合成を自動で切り替えます。macOSのデスクトップ版に対応し、FFmpegは不要です。

## GUIで声を変更する

DSHの **プラグイン → VOICEVOX読み上げ → 声の設定** を開きます。チャットコマンドは不要です。

最初に「この画面で読み上げを有効にする」を押します。自動再生が許可される環境では自動で有効になります。

1. キャラクターと声質を名前で選びます。一覧はこのMacのVOICEVOXから取得します。
2. 速度（0.5〜2倍）と音量（0〜200%）をスライダーまたは数値入力で調整します。
3. 「この設定で試聴」で、保存前の設定を確認できます。試聴文は変更でき、試聴のみを停止するボタンもあります。
4. 「設定を保存」で全チャットに反映します。保存すると現在の読み上げは停止します。

試聴だけでは設定を保存しません。ページを離れると未保存の変更は破棄されます。
「設定とキャラクターを再読み込み」で、最新の保存値とキャラクター一覧に戻せます。
別の画面やチャットで設定が変わった場合は、古い設定で上書きせず再読み込みを案内します。

## チャットからの操作

プラグインを有効にして、DSHで通常どおりチャットしてください。既定の声はずんだもん（ノーマル）、速度は1.1倍です。
VOICEVOXが起動していない場合は自動起動します。音声は読み上げを有効にしたDSHの画面側から再生されます。画面を閉じると再生は停止します。複数画面では一つだけが再生を担当し、設定画面のボタンから再生先を切り替えられます。

| コマンド | 動作 |
| --- | --- |
| `/voicevox` | ON/OFF、使用した音声合成方式、待ち区間数、直近のエラーを表示 |
| `/voicevox test` | 接続確認と音声の試聴（OFFでも使用可） |
| `/voicevox stop` | 現在の再生と待ち行列を停止。生成中の返答の続きもミュート |
| `/voicevox off` | 自動読み上げを無効化して保存 |
| `/voicevox on` | 自動読み上げを有効化して保存 |
| `/voicevox speakers` | 話者・スタイルID一覧 |
| `/voicevox speaker 3` | ずんだもん（ノーマル）に変更して保存 |
| `/voicevox speed 1.1` | 速度を変更して保存（0.5〜2） |

設定は全チャット共通です。声・速度などの変更時は現在の読み上げを停止します。
`stop`はDSHの文章生成自体を止めません。次の新しい返答から読み上げを再開します。
試聴も待ち行列の順に再生するため、すぐ試したい場合は先に `/voicevox stop` を実行してください。

## ストリーミングの動作

1. DSHの本文が少しずつ届くと、句点・改行などの区切りで音声合成を開始します。
2. 区切りがない文章も、8文字以上たまってから約700msを目安に送ります。長い区間は分割します。
3. ストリーミング対応のVOICEVOXでは、各区間の音声を受信しながら再生します。エンジンがストリーミング合成に対応していない場合は通常合成（`/synthesis`）に切り替え、区間ごとに音声ができ次第再生します。どちらも返答全体の完成を待たずに読み上げます。
4. メッセージ確定時には残りだけを読み、すでに送った本文を再度読み上げません。

700msはテキストの区切りを待つ時間です。実際の開始時間にはモデル・VOICEVOXの処理時間、再生準備、先行する音声の待ち時間も加わります。
複数チャットの音声は順番に再生し、音を重ねません。

- ユーザー入力、思考ブロック、ツール結果、サブエージェントは読み上げません。
- Markdownのコードブロック・画像・URL・タグを除外します。インラインコードとリンクの表示名は本文として読みます。
- 未完成のリンクやコードなど、読み上げ対象か確定できない構文は保留します。不完全なまま終わった構文は省略します。
- 過去の履歴を再開・フォークしても再読しません。逐次イベントがないアダプターでは確定した本文を読み上げます。
- DSHの中断・エラー・リトライ時は、該当する音声の再生と待機分を中止します。**すでに聞こえた音声は取り消せません。** リトライで同じ文章が再生成された場合は、同じ内容が再び聞こえることがあります。
- 最大3,000文字まで読み上げ、超過時は「以下省略します」。待ちは20音声区間までで、超過分はスキップし状態とログに知らせます。
- 音声区間ごとに合成するため、文のつながりで短い間や抑揚の違いが生じる場合があります。

## 必要なもの・インストール

- macOS、DeepSeek Harness（動作確認: **0.2.2-rc.5**）
- VOICEVOX Engine（動作確認: **0.26.2**、VOICEVOXアプリ **0.26.3**）。旧版では通常合成に切り替わります。
- DSHの画面を開いて音声再生を有効にすること（Web Audio APIを使用）

GitHubからソースを取得し、Node.js 22以上で依存パッケージをインストールします。

```sh
git clone https://github.com/hayashi-itrf/dsh-vvox.git
cd dsh-vvox
npm ci --ignore-scripts
```

DSHの **プラグイン → プラグインを追加 → ローカルディレクトリ** で、取得した `dsh-vvox` フォルダーを指定します。ソースを更新したときはDSHを再起動してください。

## 設定とトラブル対応

| 設定 | 既定値 | 内容 |
| --- | --- | --- |
| `enabled` | `true` | 自動読み上げ |
| `endpoint` | `http://127.0.0.1:50021` | このMacのVOICEVOX Engine |
| `speaker` | `3` | 話者のスタイルID |
| `speed` | `1.1` | 速度（0.5〜2） |
| `volume` | `1` | 音量（0〜2） |
| `autoStart` | `true` | VOICEVOXを必要時に自動起動 |
| `maxChars` | `3000` | 1回の返答の文字数上限（100〜10,000） |
| `segmentLength` | `0.3` | VOICEVOXが一度に合成する秒数（0.1〜2） |
| `flushDelayMs` | `700` | 区切りのない本文を送るまでの待ち時間（100〜5,000ms） |
| `ffplayPath` | 空文字 | 旧設定との互換用。現在は使用しません |

音が出ない場合は `/voicevox test` のエラー、Macの音量・出力先、VOICEVOXの起動を確認してください。
設定画面の音声再生状態も確認し、必要なら「この画面で読み上げを有効にする」を押してください。接続・再生に失敗してもDSHの文章生成は止めません。
自動読み上げの失敗はログと `/voicevox` の「直近のエラー」で確認できます。

本文の送信先はこのMacのループバックAPIに限定しています。外部の音声サービスへは送信しません。
音声はメモリ上で順次再生し、音声ファイルをディスクに保存しません。停止・無効化・画面終了時は通信と再生を終了します。音声を先読みする量には上限があり、回線の切断時も再生を停止します。

## 開発と検証

```sh
npm ci --ignore-scripts
npm run build
npm run check
npm test
npm run smoke
ELECTRON_RUN_AS_NODE=1 '/Applications/DeepSeek Harness.app/Contents/MacOS/DeepSeek Harness' --expose-internals scripts/dsh-smoke.cjs
```

`smoke` と `dsh-smoke` は実際のVOICEVOXの音声ストリームを検証します（スピーカーからは再生しません）。デスクトップでの実再生はGUIの試聴で確認します。
`dsh-smoke` はインストール済みDSHのAgentLoopと、テスト用の固定文を逐次出力するローカルアダプターを使います。本文の生成完了前に最初のPCMを受信できること、確定イベントで二重読みしないことを検証します。ユーザーのチャットやプロファイルは変更せず、外部のモデルにも接続しません。

参照: インストール済みDSHの `dsh-agent/src/runtime-types.ts`、`dsh-llm/src/types.ts`、`dsh-session/src/types.ts`、同梱 `dsh-doc` とVOICEVOXのローカルOpenAPI。
DSH rc.3→rc.5の移行項目は拒否エラーコードとWeb検索の変更で、このプラグインには追加の移行は不要でした。

## 設定ツール

GUIと同じ操作を行う `voicevox_settings` ツールも提供します。`state`・`speakers`・`save`・`preview`・`stop` が共通のHost処理を使います。GUIの通信はDSHの認証済みConnectionを使い、Host所有者以外の呼び出しを拒否します。
